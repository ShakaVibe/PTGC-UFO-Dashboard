# Session 2026-09-11 — Buy buttons (research only, nothing built)

Shaka wants "Buy PTGC" / "Buy UFO" buttons pointing at switch.win. The founder sent
https://docs.switch.win/ — that documents the server-side quote API (needs an API key
from the Switch team via Telegram, key must stay on a backend). Not what a Buy button
needs. Verified two simpler routes in the browser on 2026-09-11:

## A. Deep link to the Switch app (no fee share)
`https://switch.win/dapp` reads `network`, `from`, `to` from the URL
(`inputCurrency` / `outputCurrency` are aliases; `chain` / `chainId` alias `network`).
Native PLS = sentinel `0xeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeee`.

    https://switch.win/dapp?network=pulsechain&from=0xeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeee&to=0x94534EeEe131840b1c0F61847c572228bdfDDE93   (PTGC)
    https://switch.win/dapp?network=pulsechain&from=0xeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeeee&to=0x49eD499433Bee42DD34C169470feF2C8f9fAe6e6   (UFO)

Both load pre-filled; the app detects the buy tax (PTGC 5% → slippage 5.5%,
UFO 6% → 6.5%). `/dapp`'s page chunk passes only `defaultChainId` to the swap
component — **no partnerAddress**, so no fee share on this route.

## B. Embed the Switch widget (50% of the 0.10% router fee to a partner wallet)
Builder at https://switch.win/#widget. Same `network`/`from`/`to` plus colour params and
`partnerAddress` (validated as 0x + 40 hex, then passed into every quote / limit order):

    <iframe src="https://switch.win/widget?network=pulsechain&background_color=000000&font_color=ffffff&secondary_font_color=7a7a7a&border_color=01e401&backdrop_color=transparent&from=0xeeee…eeee&to=<TOKEN>&partnerAddress=<WALLET>" allow="clipboard-read; clipboard-write" width="100%" height="900px">

Verified PLS→UFO renders in the widget with tax detection and a "Powered by Switch" footer.
Wallet connect happens inside the iframe.

Caveat: the widget/dapp URL params are NOT in the docs — taken from switch.win's builder
and page source (Next.js chunks `widget/page-*.js`, `dapp/page-*.js`, `7796-*.js`).
Tell the founder we're embedding the widget so they don't change it under us.
