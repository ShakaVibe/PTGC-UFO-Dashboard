Shaka's brief: "a Buy/Sell button in the top right of each dashboard, one that looks really
good; click → the window with the widget." Route B (widget in a `<Modal>`) with the `/dapp`
deep link as a small "Open in Switch ↗" fallback; both tokens. Later in the session Shaka
pasted the two snippets from switch.win's builder (bg `000000`, border `d4af37` / `7cfc00`,

own inside the window — the widget's flip arrow handles selling. `switchWidgetUrl` now
reproduces those snippets' `src` byte-for-byte (verified with an `evalfile` probe).

  fee-share wallet `0xF8FEb…E91A8` (50 % of the 0.10 % router fee on widget trades).

  switch.win URLs are built. Colour params: bg `0a0a0a`, font white, secondary `7a7a7a`,

  widget iframe (PLS → token; sell = the widget's own flip) with a spinner until `onLoad`,
  footer with the dapp link. Bottom sheet on phones, centred card from sm. Escape / backdrop
  close; focus returns to the button (verified). `switchPair(token,'sell')` still exists for
  the dapp link / a future deep link, but the modal no longer offers a toggle.
- Header: the old goptgc `BUY` link (PTGC only, hidden on UFO) is REPLACED by the Buy/Sell
  button for both tokens. The Affiliates tab still has the goptgc onboarding link. `.buy-btn`
  CSS now carries a `--g` glow pulse (`buyGlow`, off under reduced motion) instead of the

  button next to it is already called Switch.

## Layout note (measured, don't undo)

row has no more room at 1600 than at 1280. Fixes: logo inside the button hidden from lg up,
`lg:text-xs xl:text-sm`, tracking `lg:0.06em xl:0.16em`, `lg:px-2.5 xl:px-3.5`, actions
