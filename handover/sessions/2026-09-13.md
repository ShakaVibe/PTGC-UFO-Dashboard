### Data — `data/dao-buys.json`, new generator `scripts/build-dao-buys.mjs`
- Runs as a second step of `fetch-treasury.yml` (`continue-on-error`), right after the treasury
  fetch, so it always sees fresh `treasury-wallet1-{txns,tokens}.json`.
- A **buy** = tx sent by the wallet, succeeded, `value > 0` (paid native PLS), with PTGC
  transferred TO the wallet in the same hash. PLS the router refunded in-tx
  (`internal_transactions` back to the wallet) is subtracted. **211 buys** since 2024-09-06,
  62.54B PLS ≈ $1.52M for 6.87B PTGC (lifetime avg $0.000222/PTGC). Excluded and counted:
  14 `removeLiquidityETH…` calls that also deliver PTGC (`excluded.lpRemovals`). DEXTools shows
  181 for the same wallet — it only attributes buys through pools it indexes; ours is the chain.
- **Priced on chain, no third party**: PLS/USD from `PAIR_WPLS_DAI` reserves and PTGC/USD from
  `PAIR_PTGC_WPLS` reserves at the buy's own block (`eth_call … getReserves` with a block tag —
  the public RPC serves archive state, tested back to block 20M). Effective price paid lands
  2.7–14% above market (5% tax + slippage): min/median/max ratio 1.027 / 1.050 / 1.144, no
  outliers. GeckoTerminal was ruled out: blocked from the cloud sandbox and the device VM, so it
  could not be tested, and reserves are reproducible.
- Price line on a fixed block grid: daily (`8640` blocks) from 30 days before the first buy,
  hourly (`360`) for the last 92 days, real block timestamps per point, plus `price.latest`.
  Checkpointed: the grid is extended from the previous file, buys are cached by hash → an hourly
  run is ~0.7 s and a handful of RPC calls; from scratch 26 s (`CONCURRENCY=24` single calls —
  the RPC handles 30 concurrent calls in 0.5 s but a JSON-RPC *batch* serially at ~1 s/item).
- Guards: writes only when every buy is priced; a price-line failure carries the old line forward.
  Initial backfill was run from the sandbox and committed with the code, so Actions only appends.
