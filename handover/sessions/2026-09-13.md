# Session 2026-09-13 — Buy / Sell button + switch.win widget modal (built)

Shaka's brief: "a Buy/Sell button in the top right of each dashboard, one that looks really
good; click → the window with the widget." Route B (widget in a `<Modal>`) with the `/dapp`
deep link as a small "Open in Switch ↗" fallback; both tokens. Later in the session Shaka
pasted the two snippets from switch.win's builder (bg `000000`, border `d4af37` / `7cfc00`,
partner `0xF8FEb22eeE8E1d095E995658E4c79e13522E91A8`) and said: no Buy/Sell controls of our
own inside the window — the widget's flip arrow handles selling. `switchWidgetUrl` now
reproduces those snippets' `src` byte-for-byte (verified with an `evalfile` probe).

## What changed (`index.html` only, +~90 lines)
- `ADDR.NATIVE_PLS` (switch.win's `0xeeee…` sentinel) and `ADDR.SWITCH_PARTNER` = Shaka's
  fee-share wallet `0xF8FEb…E91A8` (50 % of the 0.10 % router fee on widget trades).
- `switchPair / switchDappUrl / switchWidgetUrl` right after `TOKENS` — the only place the
  switch.win URLs are built. Colour params: bg `0a0a0a`, font white, secondary `7a7a7a`,
  border = the token's `colorHex`, backdrop transparent.
- `SwapModal` (just above `DashboardSkeleton`): `<Modal>` (gotcha 12) → token header, the
  widget iframe (PLS → token; sell = the widget's own flip) with a spinner until `onLoad`,
  footer with the dapp link. Bottom sheet on phones, centred card from sm. Escape / backdrop
  close; focus returns to the button (verified). `switchPair(token,'sell')` still exists for
  the dapp link / a future deep link, but the modal no longer offers a toggle.
- Header: the old goptgc `BUY` link (PTGC only, hidden on UFO) is REPLACED by the Buy/Sell
  button for both tokens. The Affiliates tab still has the goptgc onboarding link. `.buy-btn`
  CSS now carries a `--g` glow pulse (`buyGlow`, off under reduced motion) instead of the
  inline box-shadow.
- Button layout (v2, after Shaka saw v1 live): six mockups were rendered (Orbitron + real
  logos, `tools/harness/out/` is gitignored so they are not in the repo); Shaka picked **B** —
  logo left, BUY stacked over SELL with a hairline, SELL in white/55, no sub-text. At 1024 it
  is 86 px wide, narrower than the original BUY pill (87), so the header slack is back.
- In-window SWITCH (Shaka's ask): top-right of the modal, next to ✕, shows the OTHER token's
  logo and flips the modal to that token's widget. Modal-local `tok` state — the dashboard
  behind stays on its own token. `aria-label="Switch to UFO"` / `"Switch to PTGC"`.
- `Dashboard`: `showSwap` state; `{showSwap&&<SwapModal…/>}` rendered next to the Abduction Deck.

## Layout note (measured)
The header is capped at `max-w-7xl`, so the row has no more room at 1600 than at 1280 and
1024 is the tightest case. The v1 button (BUY / SELL side by side + sub-line) was ~60 px wider
than the old pill and clipped the "X's to a Penny" ⓘ; v2 (B) is 86 px at lg, so the stats have
their original slack. Kept from the v1 tuning, harmless: actions `lg:gap-1.5 xl:gap-2`, Switch
button `lg:px-2 xl:px-3`, and the button's own lg sizes (logo 28 px, 10 px type).
