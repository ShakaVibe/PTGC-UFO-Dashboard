## The build (same session) — `tools/kpi-v2.py` (+ `kpi-v2.css`, `kpi-v2.jsx`), run on a clean index.html
- **`KpiCardV2`** (module scope, right above `KPIContent`, with `KP_ICONS`, `KpTile`, `KpSpark`, `KpChg`, `KpInfo`): the maths of
  the old `renderKPICard` moved into it unchanged (a19 nulls → "—" / no badge; u5/u6 Value Generated from `computeValueGen`,
  the "7D EST" tag for UFO as the other token; an unknown burn window "—"). `renderKPICard` is now a one-liner that renders it,
  so the tab, the Socials "KPI Report" rows and the compare view all get the card. **The sparklines are real**: the card calls
  `useH2Series(t,d,!d)` — the SAME hook and `H2Spark` the v2 KPI tiles use (mcap = the GeckoTerminal price candles, vol / liq /
  ratio from lv-snapshots, hold from the holder history), so the compare card's other token draws its own series too. The
  Value Gen tile has no series (there is no history for delivered fees) and draws none — never a borrowed shape. Figures go
  through `H2Val` (shrink-to-fit, never an ellipsis — the DS_DOWN run's absurd stub figures proved it).
- **CSS** `kp-*` block (head `<style>`, before the LEAGUES block). The card is a **container query** unit (`container-type:
  inline-size`): under 540 px the tiles become a 2-column grid with the sparkline under the figure, the badge / ⓘ pinned
  bottom-right, the 7D tag under the chip at the right (its containing block is the chip's grid area — see the comment), the PLS
  RATIO box drops under the price, the burn block's 7D column becomes a row. That is what a phone gets AND what two cards get
  side by side at 1024 (each ~476 px).
- The v2 fire bar's eight `.p2 .p2-bar…` rules also match `.kp .p2-bar…` (selector lists; the panel's CSS is otherwise
  untouched).
- The tab's container `max-w-4xl` → `max-w-[1264px]` (two 600 px cards + the gap); the side-by-side from `lg` (was `md`);
  the controls (📷, Add / Remove) in one centred row above the cards; the loading / failed placeholders at the card's size.
  **The cards' row is `w-full`** — inside the Socials modal's `items-center` column it had no width and the card collapsed to a
  1 px line (found in the harness, fixed).
- **Found and fixed on the way: the Socials "Combined KPI Report" row has been dead since 2026-09-29** — `42f244912` (the
  Affiliates Report card) deleted the `showCombinedKPI` modal by accident; the row set the state and nothing read it.
  Restored as it was (`startWithBoth` + `startInTwitterMode` → straight into the 1200×675 share image).
- Four explainers added to `EXPLAINERS` for the card's ⓘs: `liquidity`, `liqMcap`, `volume24h`, `totalBurned` (`plsRatio`
  and `valueGenerated` already existed).
