  Today-vs-averages bars empty, while the daily chart under it was fine (it reads swap-volume.json).
- Cause: `fetchCoingeckoData()` read `coingecko-data.json` ONCE per page life (module cache, no TTL); the windows are gated on
  that copy's `lastUpdated` < 12 h (c17). The pipeline wrote the file every hour all night (commits 01:22 → 12:19 UTC checked),
  but a tab that had been open > 12 h judged it by the copy it fetched on arrival → any load() (token switch, retry ladder)
  blanked the three windows, and quickRefresh only ever refreshed the 24 h figure (a52) → stuck until a full reload. A fresh load
  on the live site showed $829,654 / $1,590,564 / $3,737,655 at once.
- Fix `tools/vol-windows-fresh.py` (idempotent, index.html md5 `94ffbe62…`): the cache re-reads after 15 min and keeps the last
  good copy on a failed read; the gate moved into one module-scope helper `cgVolWindows(token, d)` (same rules: window ≤ token age,
  monotonic, file < 12 h); quickRefresh (5 min) re-reads + re-gates the three windows. Value Generated's 7D / 30D / 90D ride on the
  same `volumeByPeriod`, so they recover too.
- Harness (cloud clone of main + the script, `CHROME=/opt/pw-browsers/chromium`): file 13 h old at load → "—" on BOTH main and
  patched; file freshened while the page stays open, `coingeckoFetchedAt=0` (= 15 min passed), Refresh → main stays "—",
  patched shows the three figures. Fresh load PTGC + UFO identical to live; file 404 → "—" before and after the refresh, no $0.
- Not changed: calculators.html has its own once-per-page copy (no freshness gate, so it never blanks — only ages).
