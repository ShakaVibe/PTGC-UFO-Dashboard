# 2026-09-23 - Socials: DAO Buys share card

**Ask (Shaka):** a DAO Buys graphic in Socials, button under DAO Treasury, in the look of the
"Latest DAO buy" tile (colours, glow, emojis kept, layout free). It opens on the latest buy, with a
good-looking switch at the top: Past 24 hrs / 7 days / 30 days / 90 days / All time.

## What was built (index.html only)
- Socials -> PTGC column, right under DAO Treasury: **DAO Buys** ("Latest buy, or any period"). Same
  pattern as its neighbours: `setSocialReturn`, switches to PTGC if needed, Escape/close returns to Socials.
- `DaoBuysSocialModal` (module scope, just above `DashboardSkeleton`): a `ShareCardModal screenshot`,
  1200x675, with the period switch in `controls` (above the card and never part of the image). It is a
  gold segmented control: Latest (with pulse dot, default) / 24H / 7D / 30D / 90D / All time, `aria-pressed`.
- Data: `fetchDaoBuys()` + `fetchFreshDaoBuys()`, deduped by hash - the same sources as the PTGC Buys chart.
  Loading or failed shows `CardLoadState` over an empty frame, with Retry.
- `computeDaoSocialView` (pure). Windows are rolling (now - N days); money is what was PAID. Worth today =
  PTGC x live price (Dashboard's `data.price` on PTGC, else `dao-buys.json` `price.latest`), "—" if none.
- Card: title row (pulse dot + LATEST DAO BUY / DAO BUYS · PAST N DAYS, date or span + count; top right
  ptgc-ufo.com, PTGC DAO Treasury, data date), hero (logo with glow, 124 px metallic amount + PTGC,
  creatures `min="Squid" max={4} ones={false}` like the tile), a detail line, a timeline strip (SVG, one
  dot per buy, area proportional to PTGC; Latest shows the last 90 days with the latest dot ringed), and four tiles:
  - Latest: Price paid · Market then · Worth today (± vs paid) · Lifetime (buy #N · $ spent)
  - Range: Buys (biggest) · Spent (PLS) · Avg cost · Worth today (± vs spent)
  - Empty range: "No DAO buys / in the past 24 hours", the last buy in the detail line, tiles Last buy ·
    Last buy size · Lifetime buys · Lifetime PTGC. It never shows a card claiming 0 PTGC.

## Why screenshot-only
The first build had Download PNG. The H2C run (`H2C=1 ... evalfile=probes/share-png-real.js`) showed
the flat gold, hard boxes where the frame glow was, and the text offset (amount over creatures). The
glow is the point of the card, and Shaka chose the same for the PTGC Buys chart card on 2026-09-14, so
the card is screenshot-only too. The offset also appears on the Burn Stats PNG in the harness, so it
may affect every downloadable card a little. That is worth a look someday, but it is not part of this change.
