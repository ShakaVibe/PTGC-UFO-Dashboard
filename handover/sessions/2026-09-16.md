## u14 — localStorage keys versioned (`LS` table, right after `SUPPLY`)
Every key the page writes is now listed once in `LS`, each carrying a version, with `lsGet(key,
shapeOk)`, `lsSet`, `lsTake` (read-and-clear) and a boot-time `lsSweep()`:
- `grays_disclaimer_v1` holds the `DISCLAIMER_VERSION` the visitor accepted (`'1'`). **Bump
  `DISCLAIMER_VERSION` when the wording in `DisclaimerModal` changes** and every device is asked
  again — the old bare `ptgc_ufo_disclaimer_accepted='true'` is upgraded to `'1'` once, so the
  current wording is not re-prompted on deploy. Verified: missing key → modal; `'0'` → modal;
  accept → `'1'`, modal gone.
- `grays_tiers_v2_<address>` — the holder-tier cache is now shape-checked before use (`ts`
  number, `tiers.ok===true`, every tier a non-negative number or null). A string count or a
  missing tier is ignored, not rendered as "0 whales". Old `grays_tiers_0x…` entries are swept.
  Only `ok:true` results were ever cached, so the check matches the writer.
- `grays_ptgc_by_ufo_pre_v1`, `grays_implied_supply_v1`, `grays_deck_pools_v1` — unchanged
  names, now aliases of `LS.*` (they already validated their shape).
- **The `ptgc_last_token` / `ptgc_nav_tab` / `ptgc_nav_view` keys keep their names.** They are the
  handoff contract with `calculators.html`, `charts.html` and `portfolio.html` (those pages set
  them, index reads them once). Renaming would touch four pages for no gain; they are listed in
  `LS` as `HANDOFF_*` and read with `lsTake`.
- Legacy `?token=X` handoff: still `replaceState` (no duplicate history entry — verified
  `history.length` 2), but now only the `token` param is dropped; `?debug=1` and anything else
  survive (`?token=UFO&debug=1` → `/?debug=1#/ufo`).

## u11 — Live Feed (`AbductionDeckModal`)
Three module-scope components hoisted out of the deck, right after `DECK_POD_POS`:
- `DeckRow` (`React.memo`) — one ground-tape row. The deck re-renders on every landing (6×
  `setTotals` per contact) and every 6 s poll; forty rows × (4 + pods) cells were rebuilt each
  time. A contact object never changes identity, so a row now renders once. `.deck-a.on` is a
  DOM class the dispatch animation adds; React never overwrites it because the row never
  re-renders. **Reduced motion: cells start lit** (`r.fresh&&!reduced`) — they used to stay dimmed
  forever because the dispatch that lights them never runs.
- `DeckScanline` — owns the half-second clock for "next scan Ns"; `tickNow` in the deck (a
  full re-render twice a second) is gone. **Contacts 24h** is now `{base, at, landed}`: the
  DexScreener 24h count at seed time, aged out evenly over 24 h, plus contacts landed since. It
  used to only ever go up between dashboard refreshes.
- `DeckPods` — the pods and the ship's "Generated" readout, with the 1.1 s count-up inside
  (`disp`/`dispRef` moved here). It used to `setDisp` on the deck itself every animation frame.
  `podRefs` is still the deck's (passed down) so the dispatch flights and the signal lines find
  the pod elements.
Also: `.deck-scan` lost `mix-blend-mode:overlay` (a full-deck blend layer composited every frame
for an effect invisible on `#0b0d12`; alpha bumped .025→.03 to compensate). `deckPodPos(n)`
returns an arc layout for n>6 instead of throwing on `pos[6]`; `cols` omits `repeat(0,…)` (invalid
CSS) when there are no pods. Learned pools (`learnPool`): partner named from `ADDR` when known
(`DECK_KNOWN_SYMBOLS`), else `symbol()`, else its short address — never "pool / ?"; `symbol()`
is not even called for known partners.

Verified in the harness (new options, see README): `DECK_LOGS=8` gives the tape synthetic
swaps — 1440×900 PTGC: 3 rows + replays landing every 7 s, lift chip on the ship, top row
dimmed until dispatch, pods $27,751/$13,875/…, readout = sum, "Contacts 24h 200", countdown
ticking; `REDUCED=1` UFO: 8 rows at once, 0 dimmed cells, 0 chips; 375×812 phone deck; `RPC_DOWN=1`
→ "chain read failed"; Home, UFO KPI, Escape + KPI walk: no console errors. Acorn scope pass
over the three hoisted components: no free identifiers outside module scope.
Not a regression but worth knowing: in the harness the UFO deck has **0 pods** (the `eth_call`
stub returns zero fees, so every bucket is filtered out) — same on the previous build.
