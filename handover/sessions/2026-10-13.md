## Built — step 1, HIDDEN (`tools/pf-v2.py`, idempotent, run on the repo root)
- `PF_V2_LIVE=false` in portfolio.html. A faint 12 px dot bottom-right (`.pf2-dotbtn`, `PfV2Dot`) flips THIS device to v2 and
  back; the choice is remembered in localStorage `grays_pf_v2_preview` (reload stays on v2). Go-live = `PF_V2_LIVE=true`.
- `PortfolioV2` (module scope, above PortfolioPage) renders the new body from the SAME state the classic body uses (agg, dp,
  portfolioData, loaders, groups, Moon Math state, the shared modals: Get/Load code, rename, Leagues). Source of the inserted
  code: `tools/pf-v2/PortfolioV2.jsx` + `tools/pf-v2/pf2.css` (`.pf2*` classes only — no new Tailwind classes, tw.css untouched).
- Wallet cards: switch (count in totals), name, address · group, value at the shown prices, PTGC/UFO split; status dot
  (green / amber loading / red failed + "Read failed · retry"); rename + remove on hover (always shown on phones). Group
  filter (shown when > 1 group), search (when > 4 wallets), phones show 6 + "Show all".
- Add capsule: address / label / group (+ "New group" → name → Create), inline message for a bad or duplicate address.
- Summary tiles: total / PTGC / UFO; **the 24 h % = today's holdings at yesterday's prices** (the price move, not trades) —
  step 2 replaces it with real balances; Moon Math → "Moon Math prices". No sparklines yet (step 2).
- Token cards per the mock; PTGC donut adds "Locked & staked" (pink) when a wallet has locks; Claimable rewards / Lock
  positions open a details box (pending stake/lock rewards, each lock with time left + goptgc.com note).
- No wallet readable → one panel "Couldn't read your wallets from the chain right now" + Retry all (instead of zeros).
- Value History + Recent Transactions: "Coming next" placeholders.
- How it works: a small modal (read-only, nothing to connect; switches; groups; PTGC staking is part of the balance;
  reflections = balance + sent − received; leagues; saved in this browser → Get/Load Code).
